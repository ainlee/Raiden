# 測試關卡設計文件

## 概述
本文件描述了測試關卡的設計和實現計劃，用於驗證遊戲的基本機制，包括玩家移動、敵人生成和碰撞檢測。

## 目標
- 驗證玩家移動機制
- 測試敵人生成和行為
- 驗證碰撞檢測系統
- 確保關卡設計的可用性和有效性

## 關卡結構

### 1. 玩家起始區域
- 位置：關卡左上角
- 玩家初始位置：(100, 100)
- 玩家精靈：使用現有的玩家資源

### 2. 敵人生成區域
- 位置：關卡右側
- 敵人類型：基本測試敵人
- 生成間隔：每3秒生成一個敵人
- 最大敵人數量：5個

### 3. 碰撞測試區域
- 位置：關卡中央
- 碰撞物件：靜態障礙物
- 碰撞類型：物理碰撞

### 4. 關卡邊界
- 左邊界：x = 0
- 右邊界：x = 800
- 上邊界：y = 0
- 下邊界：y = 600

## 實現步驟

### 1. 設計關卡佈局
- 使用Phaser的Tilemap系統創建關卡
- 定義玩家起始位置
- 定義敵人生成點
- 定義碰撞區域

### 2. 實現玩家移動
- 使用鍵盤輸入控制玩家移動
- 實現基本移動邏輯（上、下、左、右）
- 添加邊界檢查

### 3. 實現敵人生成
- 創建敵人預製物
- 實現定時生成邏輯
- 添加敵人移動行為

### 4. 實現碰撞檢測
- 設置靜態碰撞物體
- 實現玩家與敵人碰撞檢測
- 實現玩家與障礙物碰撞檢測

### 5. 集成到現有系統
- 將測試關卡添加到場景管理器
- 確保與現有遊戲系統兼容
- 添加關卡切換邏輯

### 6. 編寫測試用例
- 驗證玩家移動功能
- 驗證敵人生成和行為
- 驗證碰撞檢測
- 驗證關卡邊界

### 7. 驗證和測試
- 運行自動化測試
- 手動測試關卡
- 記錄測試結果
- 修復發現的問題

## 依賴關係
- Phaser 3.60.0
- 現有的玩家資源
- 現有的物理系統

## 预期输出
- 可運行的測試關卡
- 通過所有測試用例
- 關卡設計文件
- 測試報告
